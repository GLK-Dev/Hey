# Загрузка, установщик и системные экраны

| Файл | Что |
| --- | --- |
| `boot-splash-1920x1080.png` | экран загрузки (знак, надпись, полоса прогресса) |
| `boot-logo@2x.png` | знак + «HeOS» на прозрачном фоне — для заставки загрузчика и установщика |
| `installer-1920x1080.png` | окно установщика |
| `first-run@2x.png` | первый запуск |
| `login@2x.png`, `lock@2x.png` | экран входа и блокировки (в системе их ещё нет — нужна поддержка пользователей) |
| `about-and-crash-recovery@2x.png` | окно «О системе» и экран восстановления после сбоя |
| `accessibility-and-boot-menu@2x.png` | доступность и текстовое меню загрузчика |

Экраны с `@2x` — это доски целиком, как образец для сверки, с подписями. Числа, имена и время на них выдуманы.
Заставка загрузчика собирается из картинок при сборке: логотип + значок на каждый этап; этапы в движении — `../motion/boot-sequence.mp4`.
