# Дизайн HeOS — исходники

Здесь лежат оригиналы дизайна. В `os` и `packaging` кладутся только файлы, переведённые отсюда (HVIF, пакеты). Меняете дизайн — меняйте сначала здесь.

**Описание каждой доски и каждого набора файлов — в `CATALOG.md`.**

| Папка | Что внутри | Куда идёт в системе |
| --- | --- | --- |
| `tokens/` | `tokens.json` (все значения), `heos_design.h` | заголовок — рядом с `heos_theme.h` в SDK; цвета — в тему Industrial Dark |
| `brand/` | знак HeOS (янтарный и графитовый) | «О системе», загрузка, установщик — готовой графикой |
| `icons/apps/` | 10 значков приложений, SVG 128×128 (с «Играми» и «Маркетом») | HVIF → ресурс `vector_icon` в `.rdef` приложения |
| `icons/system/` | 24 системные иконки | HVIF → иконки системы в `os` |
| `icons/files/`, `icons/ai-files/` | 46 типов файлов, 18 файлов моделей ИИ | HVIF → MIME-база |
| `icons/small/` | 12 иконок × 16 и 24 px | ресурсы приложений, панели инструментов |
| `icons/vendors/` | 12 табличек производителей, 200×72 | «Компьютер → Устройства», NVControl |
| `sounds/` | 13 звуков v2, WAV 48 кГц стерео | пакет, события через `add_system_beep_event()` |
| `fonts/` | Onest, JetBrains Mono, Space Grotesk, Noto Sans Arabic, Noto Sans Hebrew + лицензии OFL | пакет `heos_fonts` → `/boot/system/data/fonts/ttfonts/` |
| `cursors/` | 8 курсоров: SVG + PNG 32 и 64 px, горячие точки в README | данные стандартных курсоров `app_server` |
| `wallpapers/` | 3 темы: SVG + PNG 1920×1080, 2560×1440, 3840×2160 | пакет `heos_system`, по умолчанию — через `heos_init.sh` |
| `boot/` | заставка загрузки, знак на прозрачном фоне, установщик, системные экраны | загрузчик, `src/apps/installer`, образцы для сверки |
| `motion/` | 10 анимаций и переходов: MP4 + GIF | образец для реализации, времена подобрать на системе |
| `icons/hvif/` | все значки, переведённые в HVIF (+ `.rdef` для 10 приложений) | готово к установке, см. `tools/svg2hvif/README.md` |
| `tools/svg2hvif/` | конвертер SVG → HVIF, таблица соответствия, обратная проверка | запускать после любой правки SVG |
| `themes/` | комплекты тем Night Ops и ZETA Remastered: PNG и инструкция; токены трёх тем — `tokens/themes.json` | `gui/src/theme.rs`, `tokens.rs`, `widgets.rs` |
| `charts/` | графики, прогресс и графы в трёх темах: PNG и инструкция; значения — `tokens/charts.json` | виджеты графиков в `gui/`, Монитор системы, NVControl |
| `mockups/` | ссылки на доски | для сверки при внедрении |
| `mockups/games-market/` | макеты «Игр» и «Маркета» в PNG + инструкция по внедрению | `src/apps/haikudepot` (Маркет), новое приложение «Игры» |
| `print/cd/` | PDF обложки, вкладыша и наклейки для типографии (CMYK, текст в кривых) | не часть системы |

## Важно
- В SVG значков есть тени и свечение через фильтры. HVIF их не умеет: `tools/svg2hvif` заменяет тень двумя полупрозрачными слоями, свечение пропускает. Для лучшего результата рисуйте тень формой прямо в SVG.
- В Space Grotesk нет кириллицы — только для надписи «HeOS» и латинских заголовков.
- Звуки, времена анимаций и данные на макетах — черновики и выдуманные примеры.
- Логотипов чужих брендов здесь нет и не будет: таблички производителей — значок устройства + название текстом; знаки соцсетей берутся из их официальных брендбуков.
