# Анимации и переходы

Записаны кадр за кадром с досок «Загрузка и переходы» и «Анимации ожидания», 30 кадров/с. Каждый ролик — ровно один цикл, его можно зациклить без шва.
`.mp4` — для просмотра и сверки (H.264), `.gif` — уменьшенное превью 480 px.

| Ролик | Длительность цикла | Что показывает |
| --- | --- | --- |
| boot-sequence | 6 с | этапы загрузки: ядро → диски → службы → рабочий стол, ширина 1920 |
| window-open-close | 3 с | открытие и закрытие окна |
| minimize-to-deskbar | 3 с | окно уходит в Deskbar и возвращается |
| tab-switch | 3 с | смена вкладок со сдвигом индикатора |
| loader-chamfer | 1,6 с | черта бежит по скошенной рамке — общая загрузка |
| loader-assemble | 2,4 с | знак собирается — долгие операции |
| loader-scanner | 1,4 с | бегущий блок — поиск и индексация |
| loader-corners | 1,2 с | мигающие углы — маленькие места, кнопки |
| loader-path | 2,4 с | путь по графу — размышление BFS-AI |
| loader-stream | 0,9 с | диагональный поток — без известного времени |

Времена и кривые — значения макета, их нужно подобрать на живой системе. Анимации окон (открытие, сворачивание) требуют композитора в app_server, анимации внутри окна делаются таймером и перерисовкой BView. Ролики загрузки — это демо с доски, а не готовая заставка загрузчика: в загрузчике этапы показываются поочерёдным зажиганием значков.
