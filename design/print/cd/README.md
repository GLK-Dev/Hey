# Установочный диск HeOS Preview 0.2 — файлы для типографии

| Файл | Что | Формат страницы |
| --- | --- | --- |
| `heos-cd-front-cmyk-curves.pdf` | обложка коробки 120 × 120 мм | 146 × 146 мм: вылеты 3 мм + поля с метками реза |
| `heos-cd-inlay-cmyk-curves.pdf` | вкладыш 151 × 118 мм, корешки 6,5 мм | 177 × 144 мм; пунктирные метки — линии сгиба |
| `heos-cd-label-cmyk-curves.pdf` | наклейка Ø 118 мм, печать с вылетом до Ø 124 мм, без печати внутри Ø 38 мм | 144 × 144 мм |
| `heos-cd-label-guides.pdf` | та же наклейка с линиями реза и границами — **только для проверки, не печатать** | |
| `heos-cd-front.pdf`, `heos-cd-inlay.pdf`, `heos-cd-label.pdf` | исходные RGB-версии с живым текстом — для правок | |

**Отдавать в типографию файлы `*-cmyk-curves.pdf`.** В них текст переведён в кривые, цвета — в CMYK.

Перед отправкой:
- **Заполните требования к компьютеру.** На вкладыше память и диск помечены янтарным «уточнить» — в документах проекта этих цифр нет. После правки пересоберите PDF.
- **Сверьте с требованиями типографии.** Перевод в CMYK сделан общий, без профиля типографии. Янтарь #F5A623 и голубой #00E5FF в CMYK заметно тускнеют, особенно голубой. Попросите цветопробу или пришлите типографии их профиль для пересборки.
- Графитовый фон — составной чёрный, суммарная краска около 260%. Если типография ограничивает краску сильнее, её нужно снизить.
- Для наклейки на диск уточните у типографии схему: часть принимает макет Ø 120 мм с центром Ø 15, часть — Ø 118 мм. Сейчас: рез Ø 118, вылет до Ø 124, без печати до Ø 38.
